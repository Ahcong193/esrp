# EVER STATE ROLEPLAY - language remake

This package preserves the original JSON file layout and identifiers. Russian text in the client data has been converted to a Malay-English (Malaysia) style where translations are available, and visible BLACK RUSSIA branding has been renamed to EVER STATE.

Technical CDN/API endpoints and asset filenames are intentionally preserved because changing them without the matching Ever State backend would break client downloads and connections. Some proper names, fictional place names, model names and less common descriptive phrases may remain in the source language or retain their original spelling. Review these in-game before production use.
